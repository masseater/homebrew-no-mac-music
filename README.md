# homebrew-no-mac-music

Homebrew tap for [NoMacMusic](https://github.com/masseater/no-mac-music).

## Install

```sh
brew install --cask masseater/no-mac-music/no-mac-music
```

Or tap first:

```sh
brew tap masseater/no-mac-music
brew install --cask no-mac-music
```

After install, grant **Accessibility** and **Input Monitoring** in
System Settings > Privacy & Security.
